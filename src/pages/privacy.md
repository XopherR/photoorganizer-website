_Last updated_: July 29, 2026

SnapAtlas is designed around local photo and video libraries. This page explains the privacy expectations for website visitors and for people using SnapAtlas workflows.

## Product privacy model

- SnapAtlas is intended for local file libraries.
- Normal organization, duplicate review, folder merge, and HEIC conversion workflows do not require cloud upload.
- Metadata and location details come from folders and files you choose to process.

## Website data

This website is a static marketing and documentation site.

- We do not publish contact details or analytics identifiers by default in this template.
- If you contact us, you choose what information to send.
- If you share screenshots, logs, or metadata for support, only send what you are comfortable disclosing.

## File safety expectations

- Use **What-If mode** before major changes.
- Review staged cleanup results before permanent deletion.
- Keep backups before large reorganizations.

## Optional tools

You only need external tools such as ExifTool when you want to write or edit metadata. Reading metadata does not require it.

## Third-party links

This site may link to external resources such as GitHub or documentation references. Those services have their own privacy policies.

## Changes

This policy may be updated as the product and support process evolve. Please review it periodically.
