SnapAtlas is designed for careful cleanup of local file libraries.

## Safety model

- **What-If mode** for dry runs
- staged cleanup before permanent deletion
- activity logs for operation review

## Privacy model

- designed for local file libraries
- processes folders you choose
- metadata and location usage depends on your configuration and file contents

## Best practice

Always keep a backup before large reorganizations.
