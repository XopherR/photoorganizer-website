When a library feels chaotic, organization should come before aggressive cleanup.

## Recommended workflow

1. Turn on **What-If mode**
2. Run deep scan
3. Run organize by date and location
4. Review outliers and exceptions
5. Apply for real when results look correct

## Why this order works

- date and location grouping gives structure first
- outlier review catches unclear files early
- preview mode reduces risk before broad moves

## Best practice

Start with a single year, month, or import folder first. Once the output looks right, expand to the rest of the archive.
