When a result looks wrong, reduce scope and verify one operation at a time.

## Metadata seems missing

- run deep scan
- confirm files actually contain EXIF metadata
- only install optional tools if you need metadata editing

## Duplicate results seem off

- adjust visual similarity threshold
- review exact and visual duplicates separately

## Operations feel slow

- process smaller scopes first
- run one heavy operation at a time
- let initial indexing finish before major actions
