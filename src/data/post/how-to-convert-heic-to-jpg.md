HEIC conversion is useful when other tools or people need JPG files.

## Recommended steps

1. Run HEIC conversion
2. Verify JPG output
3. Confirm originals are staged as expected

## Use it deliberately

Run HEIC conversion after scans and organization are already in good shape. That keeps compatibility work from getting mixed into broader cleanup.
