SnapAtlas helps you clean up and organize large photo and video libraries on your computer.

## Start with your photo root folder

Choose the top-level folder that contains your library. This keeps scans, cleanup recommendations, and later review inside the right scope.

## Run a scan first

Start with a normal scan for a quick look at structure and counts.

Use a deep scan when you want:

- fuller metadata extraction
- better duplicate detection coverage
- more confidence before large cleanup

## Turn on What-If mode

Before major changes, enable **What-If mode**. This lets you preview actions without moving files.

## Recommended order

1. Organize by date and location
2. Review outliers
3. Run duplicate detection
4. Merge related folders
5. Convert HEIC if needed

## Review results before continuing

Use Activity and Duplicates views to verify what changed after each step.

## Optional tool: ExifTool

You only need ExifTool when you want to write or edit metadata. Reading metadata works without it.
