description: What data SnapAtlas uses and how local-first workflows work.
---

SnapAtlas is designed around local library workflows.

## Core privacy model

- You choose which folders are scanned
- Processing is focused on local files and metadata
- Optional location/geocoding behavior depends on your configuration

## Practical guidance

- Review settings before large operations
- Use What-If mode for safer previews
- Keep routine backups of your library
