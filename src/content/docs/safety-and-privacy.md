## Safety model

- **What-If mode** for dry runs
- Staging-based cleanup (soft delete workflow)
- Activity logs for operation review

## Privacy model

- Designed for local file libraries
- Processes data from folders you select
- Metadata/location usage depends on your configuration

## Best practice

Always keep a backup before large reorganizations.
