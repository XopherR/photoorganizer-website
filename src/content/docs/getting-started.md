---
title: Getting Started
description: Set up SnapAtlas and run your first safe cleanup.
---

## 1) Select your photo root folder

Choose the top-level folder that contains your photo library.

## 2) Run a scan

Start with a scan.  
Use a deep scan when you want full metadata and duplicate detection coverage.

## 3) Turn on What-If mode

Before major changes, enable **What-If mode** to preview actions without moving files.

## 4) Run one operation at a time

Recommended order:

1. Organize by date/location
2. Review outliers
3. Run duplicate detection
4. Merge folders
5. Convert HEIC if needed

## 5) Review results

Use the Activity and Duplicates views to verify what changed.

## Optional tool: ExifTool

You only need ExifTool for editing/writing metadata.  
Reading metadata works without it.
