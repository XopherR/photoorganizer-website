---
title: Accuracy and Limits
description: Understand how matching works and where human review is still important.
---

SnapAtlas uses two matching approaches:

- **Exact duplicate detection** for byte-identical files
- **Visual similarity detection** for near-identical images

## What to expect

- Exact matching is precise for identical content.
- Visual matching is powerful but can occasionally flag different photos that look very similar.

## Recommended review strategy

1. Review exact matches first
2. Review visual matches second
3. Tune visual threshold if needed
4. Confirm staged removals before final delete
