---
title: Workflow Playbooks
description: Practical routines for first-time cleanup and ongoing maintenance.
---

## First weekend cleanup

1. Select root folder
2. Run deep scan
3. Enable What-If mode
4. Organize by date/location
5. Review outliers
6. Run duplicate detection
7. Apply in stages

## Monthly maintenance

1. Scan recent folders
2. Run duplicate detection for new imports
3. Review merge recommendations
4. Verify staged removals
5. Keep a short operations checklist

## Migration cleanup (old drives/cloud exports)

1. Consolidate sources under one root
2. Scan and normalize structure
3. Organize by date/location
4. Deduplicate in review batches
5. Validate final hierarchy
