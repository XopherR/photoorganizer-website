SnapAtlas is designed for safety-first library cleanup.

## Built-in safeguards

- **What-If mode** for previewing actions
- **Staged cleanup** instead of immediate permanent deletion
- **Activity logs** to review what happened
- **Incremental workflows** so you can process in smaller batches

## Recommended recovery-friendly process

1. Run a preview pass in What-If mode
2. Apply changes to a small test scope
3. Verify results and staging locations
4. Expand to the full library

## Best practice

Keep a backup before large-scale reorganizations.
