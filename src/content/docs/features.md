title: Features
description: What SnapAtlas can do for your photo library.
---

## Folder browsing and indexing

- Navigate your folder tree
- View file/folder counts
- Keep library views up to date with background indexing

## Metadata extraction

- Reads EXIF metadata where available
- Uses metadata to drive organization and analysis

## Duplicate detection

- **Exact duplicates**: identical file content
- **Visual duplicates**: photos that look the same but may differ in size/encoding/editing

## Organize by date and location

- Creates date-based folders (for example, `2025-07-29`)
- Can use GPS/location metadata for clearer grouping
- Sends unclear items to outliers for manual review

## Folder merge recommendations

- Detects date-related folders that likely belong together
- Helps consolidate split import batches

## HEIC to JPG conversion

- Converts HEIC/HEIF to JPG
- Preserves originals in a safe staging flow
